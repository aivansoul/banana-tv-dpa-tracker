    Zapier

    À faire

    Pour les Zaps qui déplacent des données clients entre vos outils.

    Automation Prioritaire Intégré au contrat Copie signée sur demande
    Démarche à suivre ⌄
    1. Recenser les Zaps qui transportent des données clients (CRM, formulaires, e-mails, transcriptions) et les applications tierces connectées.
    2. Le DPA est déjà incorporé aux Terms of Service : aucune signature n’est requise pour qu’il s’applique.
    3. Pour le dossier, générer une copie signée électroniquement depuis la page DPA — Zapier l’envoie via Dropbox Sign, en deux e-mails (demande de signature, puis PDF signé).
    4. Noter que Zapier, Inc. (États-Unis) est le sous-traitant : transferts couverts par les clauses contractuelles types (modules 2 et 3) et le Data Privacy Framework.

    6. Point d’attention : le DPA de Zapier ne couvre plus les données une fois transférées vers une application tierce connectée. Chaque application au bout d’un Zap a besoin de son propre DPA.
